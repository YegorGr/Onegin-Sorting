# Евгений Онегиность

## Taskность
Требуется прочитать исходный файл. Отсортировать строчки в файле сначала по возрастанию, потом по убыванию, а также вывести исходный текст без именения. Весь отсортированный текст требуется записать в один файл. При этом все не буквенные символы (кавычки, цифры и т.д.) требуется пропускать (не сравнивать буквы с НЕ буквами). 

## Архитектурность проекта
Так как в проекте всего 500 строк, то разбиение на файлы было решено скипнуть. 

## Алгоритмость решения

* Чтение из файла в буффер 
* Создание массива структур (`index`), а также его копии (`copyindex`) для последущего вывода неотсортированной версии Онегиности.
* Сортировка алгоритмом QuickSort с использование собственного компоратора для строк, а также обратного компоратора. Первая сортировка происходит встроенным алгоритмом `qsort()` (`#include <stdlib.h>`), вторая сортировка происходим собственным алогритмом `myqsort()`.
* Вывод всех сортировка в файл 'Sorted Onegin.txt'.

## Фичность 

### Юзабелность
Организовано два режима ввода: считывает аргументы командной строки (нужно указать из какого файла считывать текст), а также, если не указывать аргументы командой строки, то программа запускается в режиме "Юзерность-френдли" - в нем можно будет указать имя в файле уже в самой консоли OC.

### Утечконепроницаемость 
В программе существует функция `FreeMem()`, которая отвечает за закрытие всех блоков динамической памяти, а также обнуляет все указатели на закрытые блоки памяти.

### Оптимизированность 
Обратный компоратор не использует `strlen()` каждую новую итерацию. Он получает длины строк из структуры. Это сильно уменьшает сложность алгоритма из O(n) --> O(1).

### Ошибкочитаемость 
Все ошибки печатаются в поток `stderr`, при этом используется `errno` и функция  `strerror`.

### Функциразбиваемость 
Модульная программа, гениальный main.

## Ассертность 
Добавлено большое кол-во ассертов. Для запуска в отладочном режиме уберите `#define NDEBUG`
